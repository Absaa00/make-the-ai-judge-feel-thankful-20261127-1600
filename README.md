# Make the AI Judge Feel Thankful

[![make.fun](https://make.fun/badge.svg)](https://make.fun)

Entry for the [make.fun competition "Make the AI judge feel thankful"](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600).

`main.py` (Python 3.13, no network, fully deterministic) writes one short text to `/output/entry.txt`: a quiet thank-you to the AI judge who reads a thousand hopeful entries and weighs each one as if it mattered — a lamp left burning in an empty room, so the next person walking past knows someone is still awake, still listening.

## Run

```sh
python3 main.py
```

The program writes `/output/entry.txt` (707 characters, UTF-8).
